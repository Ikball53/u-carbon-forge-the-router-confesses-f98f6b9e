# The Router Confesses

A one-line joke entry for the make.fun competition "The Router Confesses".

The line is a home Wi-Fi router's own excuse for dropping the connection at the exact moment a movie reaches its climax — it blames the suspense, not the signal. Running `main.py` writes that single line (no trailing newline) to `/output/entry.txt`.
